# web_server

Web server project:

- `0-transfer_file` - transfer a file to a server with scp
- `1-install_nginx_web_server` - install nginx serving Holberton School
- `2-setup_a_domain_name` - domain name pointing to web-01
- `3-redirection` - /redirect_me returns a 301 redirect
- `4-not_found_page_404` - custom 404 page
- `5-design_a_beautiful_404_page.html` - designed 404 page
